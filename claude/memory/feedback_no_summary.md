Do not write a summary at the end of responses unless the user explicitly asks for one.

**Why:** User finds unsolicited summaries unnecessary.

**How to apply:** Skip the closing "Here's what was done / Here's what was created" paragraph entirely. Just stop after the last meaningful output.
